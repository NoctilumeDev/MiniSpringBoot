MiniSpringBoot 全链路演示

这是由 StaticResourceHandler 从 classpath 的 static/ 目录真实托管的静态页，证明静态资源能力已落地。

GET/hello — MVC + @RequestParam
GET/users/1 — MVC + @PathVariable + @ResponseBody
GET/void — 空响应 200
GET/capability/aop/order — AOP 织入（@Before/@After/@Around）
GET/capability/aop/fail — AOP 异常原样透传（500）
GET/capability/autoconfig — 自动配置兜底 + 条件装配
GET/capability/starter/format — Starter SPI 自动装配
